# API reference

This document is a **curated** reference for the most-used endpoints. Every endpoint, full request / response schema, and error model is also auto-generated by FastAPI:

- Swagger UI — <http://localhost:8000/docs>
- ReDoc — <http://localhost:8000/redoc>
- Raw OpenAPI JSON — <http://localhost:8000/openapi.json>

For ready-to-run example requests, see [`examples/api.http`](examples/api.http).

## Conventions

- Base URL: `/` (no prefix). The frontend sets `VITE_API_BASE_URL=https://your-render-url`.
- Auth: every endpoint except `/health`, `/auth/register`, and `/auth/login` requires a valid JWT.
  - Preferred: `Cookie: token=<jwt>` (set automatically by `/auth/login`).
  - Legacy: `Authorization: Bearer <jwt>`.
- Content type: `application/json` for everything except `/uploads/statement` and `/uploads/preview`, which take `multipart/form-data`.
- All IDs are UUIDs; all amounts are `Numeric(12, 2)` (INR, 2 decimal places); all dates are ISO `YYYY-MM-DD`.
- Errors use FastAPI's default `{"detail": "..."}` shape with the appropriate HTTP status.

## Auth — `/auth`

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/auth/register` | Create a user. Sets `token` cookie. Returns `{access_token, token_type}`. `409` if email taken. |
| `POST` | `/auth/login` | Log in. Sets `token` cookie. Returns `{access_token, token_type}`. `401` on bad credentials. |
| `POST` | `/auth/logout` | Clears the `token` cookie. `204`. |
| `GET` | `/auth/me` | Returns `{id, email}` for the caller. |

```http
POST /auth/login
Content-Type: application/json

{"email": "you@example.com", "password": "your-password"}
```

Tokens are JWTs (HS256) with `sub=<user uuid>`, `aud=authenticated`, and a 30-day expiry.

## Budget — `/budget`

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/budget` | Create budget entries for a year. Body: `{year, entries: [{category_id, allocated_amount}]}`. `409` if any category already has a plan for that year. |
| `GET` | `/budget/{year}` | List the user's budget plans for `year`. |
| `PUT` | `/budget/{id}` | Update one plan's `allocated_amount`. |
| `DELETE` | `/budget/{id}` | Delete one plan. |

`allocated_amount` is **annual** — convert from monthly on the client.

## Uploads — `/uploads`

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/uploads/preview` | Dry-run a PDF; returns parsed rows without persisting. Multipart `file=`. |
| `POST` | `/uploads/statement` | Parse a PDF and persist rows as `raw_transactions`. `409` if the file (by SHA-256) has already been imported. |
| `POST` | `/uploads/preview-text` | Dry-run a pasted statement blob. Body: `{text: "..."}`. |
| `POST` | `/uploads/text-import` | Persist rows from a pasted blob. |

Duplicate detection compares the SHA-256 of the file body against `uploaded_files` for the caller; if the prior import has had all its raw rows deleted, the historical record is cleared so the file can be re-imported.

## Transactions — `/transactions`

### Raw (the holding area)

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/transactions/raw` | List raw rows. Query: `status` (pending / processed / deleted), `include_deleted` (bool). |
| `POST` | `/transactions/raw` | Manually add a raw row (no upload). |
| `DELETE` | `/transactions/raw/{id}` | Soft-delete a raw row. |
| `PATCH` | `/transactions/raw/{id}/restore` | Undo a soft-delete. |

### Processing

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/transactions/auto-categorise` | Run RapidFuzz over pending raw rows. Body: `{save_mapping: bool}`. Returns the new processed rows. |
| `GET` | `/transactions/pending-manual` | Rows still without a category after auto-categorise. |
| `POST` | `/transactions/process` | Manually categorise one raw row. Body: `{raw_txn_id, category_id, tag_ids?, shares?, notes?, save_mapping?}`. |

### Processed (the analytics-ready table)

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/transactions/processed` | List processed rows. Filters: `year`, `month`, `category_id`, `tag_id`, `txn_type`. |
| `PATCH` | `/transactions/processed/{id}` | Edit category / tags / shares / notes / `txn_type`. |
| `DELETE` | `/transactions/processed/{id}` | Hard-delete a processed row (raw row stays). |
| `POST` | `/transactions/processed/bulk-tag` | Apply or remove tags across many rows at once. |
| `PATCH` | `/transactions/processed/{txn_id}/shares/{person_id}/settled` | Toggle settled flag on one share. |

## Categories — `/categories`

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/categories` | List all categories for the user. |
| `POST` | `/categories` | Create. `409` if name exists (case-insensitive). |
| `PATCH` | `/categories/{id}` | Rename. |
| `DELETE` | `/categories/{id}` | Delete. `409` if referenced by any budget plan, mapping, or processed transaction. |

Category names are stored case-folded; the frontend renders them title-cased.

## Category mappings — `/category-mappings`

Learned rules of the form "description matching this pattern → use this category".

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/category-mappings` | List. |
| `DELETE` | `/category-mappings/{id}` | Delete. |

New mappings are usually created implicitly by `POST /transactions/process` with `save_mapping: true`.

## Dashboard — `/dashboard`

All endpoints accept `period_mode=calendar|fy` (default `calendar`). In `fy` mode, `year` is the fiscal-year start (`year=2025` → Apr 2025 – Mar 2026) and `month` 1–12 maps to Apr – Mar. See [`docs/GLOSSARY.md`](GLOSSARY.md#period-mode).

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/dashboard/summary` | Budget vs. actual per category for one `(year, month)`. |
| `GET` | `/dashboard/monthly-trend` | Per-month spend over a year, grouped by category. |
| `GET` | `/dashboard/multi-month-summary` | Aggregated summary across multiple months in one call. |
| `GET` | `/dashboard/split-ledger` | Per-person net balance (owed to / by you). |
| `GET` | `/dashboard/ytd` | Year-to-date totals per category. |

## Backup — `/backup`

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/backup/export` | Full JSON export of every user-owned row. |
| `POST` | `/backup/import` | Import a previously-exported JSON. Idempotent on the `(user_id, content_hash)` constraint of `uploaded_files`. |

## Admin — `/admin`

Bulk wipes for local development and testing. Every endpoint deletes only rows owned by the calling user.

| Method | Path | Deletes |
|---|---|---|
| `DELETE` | `/admin/transactions/raw` | All raw transactions. |
| `DELETE` | `/admin/transactions/processed` | All processed transactions + their shares + `transaction_tags` joins. |
| `DELETE` | `/admin/categories` | All categories + their mappings (only if no budget plans / processed rows reference them). |
| `DELETE` | `/admin/budget` | All budget plans. |
| `DELETE` | `/admin/persons` | All persons (fails if any shares reference them). |
| `DELETE` | `/admin/all` | Everything user-owned. |

## Health — `/health`

`GET /health → 200 {"status": "ok"}`. Unauthenticated. Used by Render's health probe.
